# 🚀 Настройка автоматической отправки Sitemap в Яндекс.Вебмастер

## ✅ Что уже готово:

1. **Backend функция развернута**: `https://functions.poehali.dev/24646cdf-f7b2-49c4-9848-31a7546faf8f`
2. **Sitemap работает**: `https://mosoblconnect.ru/sitemap.xml`
3. **Автоматическое уведомление** при обновлении контента

## 📋 Что нужно сделать:

### Шаг 1: Получить OAuth токен для Яндекс.Вебмастер API

1. **Откройте**: https://oauth.yandex.ru/client/new
2. **Заполните форму**:
   - Название сервиса: `NetConnect Sitemap Auto`
   - Платформы: выберите **"Веб-сервисы"**
   - Callback URL: `https://mosoblconnect.ru` (или любой URL)
   
3. **Выберите права доступа**:
   - Найдите раздел **"Яндекс.Вебмастер"**
   - Отметьте: `webmaster:importanturl`
   
4. **Нажмите "Создать приложение"**

5. **Получите токен**:
   - Скопируйте **ID приложения**
   - Откройте URL (замените YOUR_CLIENT_ID):
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=YOUR_CLIENT_ID
   ```
   - Разрешите доступ
   - Скопируйте **токен из URL** (после `#access_token=`)

### Шаг 2: Найти User ID в Яндекс.Вебмастер

1. Откройте: https://webmaster.yandex.ru/
2. Посмотрите на URL в адресной строке:
   ```
   https://webmaster.yandex.ru/site/https:mosoblconnect.ru:443/dashboard/?user_id=XXXXXXXX
   ```
3. Скопируйте значение после `user_id=` (например: `12345678`)

### Шаг 3: Добавить секреты в проект

В редакторе poehali.dev появились запросы на добавление секретов:

1. **YANDEX_WEBMASTER_API_KEY** - вставьте OAuth токен из Шага 1
2. **YANDEX_WEBMASTER_USER_ID** - вставьте User ID из Шага 2

## 🔍 Проверка работы:

1. Откройте функцию в браузере
2. Если секреты настроены правильно - увидите: `"success": true`
3. Проверьте в Яндекс.Вебмастер:
   - Индексирование → Файлы Sitemap
   - Должна появиться запись об обновлении

## ❓ Возможные ошибки:

### "Не настроены ключи API"
→ Добавьте секреты в проект (см. Шаг 3)

### "401 Unauthorized"
→ Проверьте правильность OAuth токена, возможно истёк срок

### "403 Forbidden"
→ Убедитесь что выбрали права `webmaster:importanturl` при создании приложения

### "404 Not Found"
→ Проверьте что сайт добавлен в Яндекс.Вебмастер
