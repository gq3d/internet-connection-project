# Документация по SEO и Sitemap

## Структура SEO-оптимизации

### 1. XML Sitemap (Карта сайта)

**Расположение:** `/public/sitemap.xml`

Карта сайта включает все страницы проекта:
- Главная страница (приоритет 1.0)
- 6 страниц услуг (приоритет 0.9)
- 32 страницы городов (приоритет 0.7)

**Всего страниц:** 39

#### Страницы услуг:
- `/services/internet` - Беспроводной интернет
- `/services/satellite` - Спутниковый интернет
- `/services/wifi` - Wi-Fi оборудование
- `/services/security` - Охранные системы
- `/services/surveillance` - Видеонаблюдение
- `/services/cellular-booster` - Усиление сотовой связи

#### Города Московской области:
Москва, Подольск, Красногорск, Химки, Мытищи, Люберцы, Домодедово, Сергиев Посад, Коломна, Пушкино, Зеленоград, Щёлково, Видное, Дубна, Истра, Орехово-Зуево, Клин, Фрязино, Лобня, Ногинск, Реутов, Красноармейск, Дмитров, Серпухов, Егорьевск, Лыткарино, Солнечногорск, Жуковский, Старая Купавна, Бронницы, Чехов, Кашира

### 2. Robots.txt

**Расположение:** `/public/robots.txt`

Правила для поисковых роботов:
- Разрешен доступ ко всем страницам
- Запрещены: `/api/`, `/admin/`, `*.json`
- Crawl-delay: 1 секунда для Yandex и Google
- Указан путь к sitemap.xml
- Определен основной домен (Host)

### 3. Хлебные крошки (Breadcrumbs)

**Компонент:** `/src/components/Breadcrumbs.tsx`

Автоматически генерирует:
- Визуальную навигацию на странице
- Schema.org разметку (BreadcrumbList)

Добавлены на страницы:
- ✅ Все страницы услуг
- ✅ Все страницы городов

### 4. SEO Hook

**Файл:** `/src/hooks/useSEO.tsx`

Динамическое управление метатегами:
- `<title>` - заголовок страницы
- `<meta description>` - описание
- `<meta keywords>` - ключевые слова
- Open Graph теги (для соцсетей)
- Twitter Card теги
- Canonical URL
- Структурированные данные (JSON-LD)

### 5. Структурированные данные (Schema.org)

#### Главная страница (`index.html`):
- `TelecommunicationsProvider` - информация о провайдере
- `BreadcrumbList` - навигация
- `FAQPage` - часто задаваемые вопросы

#### Страницы услуг:
- `Service` - описание услуги
- `Offer` - тарифы и цены
- `AggregateRating` - рейтинги

#### Страницы городов:
- Динамические метатеги через `useSEO`
- `BreadcrumbList` через компонент Breadcrumbs

## Автоматическая генерация Sitemap

### Скрипт генерации

**Файл:** `/scripts/generate-sitemap.ts`

Автоматически генерирует sitemap.xml на основе:
- Списка городов
- Списка страниц услуг
- Актуальной даты

**Запуск скрипта:**
```bash
bun run scripts/generate-sitemap.ts
```

**Или через npm script (если добавлен):**
```bash
npm run generate:sitemap
```

### При добавлении новой страницы:

1. Добавьте URL в `/scripts/generate-sitemap.ts`
2. Запустите скрипт генерации
3. Новый sitemap.xml будет создан в `/public/`

## Интеграция с поисковыми системами

### Google Search Console

1. Зайдите в Google Search Console
2. Добавьте свойство: `https://mosoblconnect.ru`
3. Отправьте sitemap: `https://mosoblconnect.ru/sitemap.xml`

### Яндекс.Вебмастер

1. Зайдите в Яндекс.Вебмастер
2. Добавьте сайт: `https://mosoblconnect.ru`
3. Индексирование → Файлы Sitemap
4. Добавьте: `https://mosoblconnect.ru/sitemap.xml`

### Проверка Sitemap

**Онлайн инструменты:**
- [XML Sitemap Validator](https://www.xml-sitemaps.com/validate-xml-sitemap.html)
- [Google Search Console](https://search.google.com/search-console)

**Локальная проверка:**
```bash
# Проверить sitemap доступен
curl https://mosoblconnect.ru/sitemap.xml

# Проверить robots.txt
curl https://mosoblconnect.ru/robots.txt
```
