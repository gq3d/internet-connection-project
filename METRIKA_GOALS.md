# Цели Яндекс.Метрики для городских страниц

Этот документ содержит рекомендации по настройке целей в Яндекс.Метрике для отслеживания конверсий на страницах городов.

## ID счетчика
**104206748**

## Настроенные события (JavaScript)

### 1. city_page_view
**Описание**: Просмотр страницы города  
**Параметры**:
- `city_name` - название города (например, "Красногорск")
- `city_slug` - slug города (например, "krasnogorsk")

**Как настроить цель**:
1. Тип: JavaScript-событие
2. Идентификатор: `city_page_view`
3. Название: "Просмотр страницы города"

---

### 2. phone_click
**Описание**: Клик по номеру телефона  
**Параметры**:
- `source` - источник клика (например, "cta_block_city_78", "header_city")
- `city_name` - название города

**Как настроить цель**:
1. Тип: JavaScript-событие
2. Идентификатор: `phone_click`
3. Название: "Клик по телефону"

---

### 3. whatsapp_click
**Описание**: Клик по кнопке WhatsApp  
**Параметры**:
- `source` - источник клика (например, "floating_button_city", "footer_city")
- `city_name` - название города

**Как настроить цель**:
1. Тип: JavaScript-событие
2. Идентификатор: `whatsapp_click`
3. Название: "Клик по WhatsApp"

---

### 4. service_interest
**Описание**: Интерес к определенной услуге  
**Параметры**:
- `service_name` - название услуги
- `city_name` - название города

**Как настроить цель**:
1. Тип: JavaScript-событие
2. Идентификатор: `service_interest`
3. Название: "Интерес к услуге"

---

### 5. cta_click
**Описание**: Клик по CTA (Call-to-Action) блоку  
**Параметры**:
- `cta_type` - тип CTA (например, "phone_contact", "order_button")
- `city_name` - название города

**Как настроить цель**:
1. Тип: JavaScript-событие
2. Идентификатор: `cta_click`
3. Название: "Клик по CTA"

---

## Инструкция по добавлению целей в Яндекс.Метрике

1. Перейдите в настройки счетчика: https://metrika.yandex.ru/dashboard?id=104206748
2. Выберите **Настройки → Цели**
3. Нажмите **Добавить цель**
4. Выберите тип **JavaScript-событие**
5. Введите идентификатор из списка выше
6. Укажите понятное название
7. Сохраните

## Рекомендуемые сегменты для анализа

### По городам
- Создайте сегменты для топ-10 городов по трафику
- Отслеживайте конверсии отдельно по каждому городу

### По источникам кликов
- Сравните эффективность разных источников кликов (CTA блок vs Header vs Footer)
- Оптимизируйте размещение контактов на основе данных

### Воронка конверсии для города
1. Просмотр страницы города (`city_page_view`)
2. Интерес к услуге (`service_interest`)
3. Клик по телефону/WhatsApp (`phone_click` или `whatsapp_click`)

## Примеры отчетов

### 1. Эффективность городских страниц
**Метрика**: Соотношение `city_page_view` к `phone_click` или `whatsapp_click`  
**Цель**: Понять, какие города дают лучшую конверсию

### 2. Популярные источники контактов
**Метрика**: Группировка событий `phone_click` и `whatsapp_click` по параметру `source`  
**Цель**: Определить, где лучше размещать контактную информацию

### 3. Путь пользователя
**Метрика**: Последовательность событий от `city_page_view` до целевого действия  
**Цель**: Оптимизировать user journey на городских страницах
