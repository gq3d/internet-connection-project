### Функциональность хлебных крошек:

#### ✅ Навигация:
- **"Главная"** - ссылка на главную страницу `/`
- **Промежуточный уровень** ("Услуги" / "Покрытие") - ссылка на главную `/`
- **Текущая страница** - НЕ является ссылкой, только текст

#### ✅ Визуальное оформление:
- Иконка домика для главной страницы
- Стрелки `>` между элементами (ChevronRight)
- Наведение курсора меняет цвет на primary
- Текущая страница выделена жирным шрифтом

#### ✅ SEO оптимизация:
- Schema.org разметка `BreadcrumbList` для всех страниц
- Правильные позиции в иерархии (1, 2, 3...)
- Canonical URLs в структурированных данных
- Aria-label для доступности

#### ✅ Доступность (Accessibility):
- `<nav aria-label="Хлебные крошки">`
- Семантичный HTML (`<ol>`, `<li>`)
- Правильная структура для скринридеров

### Компоненты проекта:

1. **Breadcrumbs.tsx** (`/src/components/Breadcrumbs.tsx`)
   - Основной компонент хлебных крошек
   - Автоматическая генерация Schema.org разметки
   - Поддержка React Router Link

2. **useSEO.tsx** (`/src/hooks/useSEO.tsx`)
   - Динамическое управление метатегами
   - Интеграция с хлебными крошками

### Как проверить работу:

1. **Визуальная проверка:**
   ```
   Откройте любую страницу услуг или городов
   → Под шапкой должны быть хлебные крошки
   → Клик на "Главная" должен вернуть на главную страницу
   ```

2. **Проверка SEO:**
   ```
   Откройте DevTools (F12)
   → Elements → <head>
   → Найдите <script type="application/ld+json" id="breadcrumb-schema">
   → Должен быть JSON с BreadcrumbList
   ```

3. **Проверка доступности:**
   ```
   Откройте DevTools → Accessibility
   → Найдите nav элемент с aria-label="Хлебные крошки"
   → Должна быть корректная структура списка
   ```
