# Инструкция по переиндексации городских страниц в Яндексе

## Проблема
Яндекс проиндексировал кириллические URL городов (`/city/москва`, `/city/жуковский` и т.д.) с неправильным canonical URL, указывающим на главную страницу `https://mosoblconnect.ru`.

## Решение
Все кириллические URL теперь:
1. ✅ Автоматически редиректят на латинские версии (`/city/moskva`, `/city/zhukovskiy`)
2. ✅ Имеют `<meta name="robots" content="noindex, nofollow">` до редиректа
3. ✅ Устанавливают правильный canonical на латинский URL

## Шаги для очистки индекса Яндекса

### 1. Проверьте текущее состояние
Откройте Яндекс.Вебмастер: https://webmaster.yandex.ru/

**Индексация → Страницы в поиске**
- Найдите все страницы с кириллическими URL: `/city/москва`, `/city/красногорск` и т.д.
- Они должны показывать статус "Неканоническая"

### 2. Удалите старые URL из индекса (Опционально)
Если хотите ускорить процесс:

**Индексация → Удаление URL**
1. Добавьте каждый кириллический URL для удаления:
   - `https://mosoblconnect.ru/city/москва`
   - `https://mosoblconnect.ru/city/жуковский`
   - `https://mosoblconnect.ru/city/дмитров`
   - `https://mosoblconnect.ru/city/домодедово`
   - И все остальные кириллические варианты

2. Выберите тип: **Временно удалить из поиска**
3. Подождите 1-2 дня

### 3. Запросите переобход правильных URL
**Индексация → Переобход страниц**

Добавьте латинские URL для переобхода:
- `https://mosoblconnect.ru/city/moskva`
- `https://mosoblconnect.ru/city/krasnogorsk`
- `https://mosoblconnect.ru/city/zhukovskiy`
- `https://mosoblconnect.ru/city/dmitrov`
- `https://mosoblconnect.ru/city/domodedovo`

### 4. Проверьте Sitemap
**Индексация → Файлы Sitemap**

Убедитесь, что sitemap содержит только латинские URL:
- URL sitemap: `https://mosoblconnect.ru/sitemap.xml`
- Проверьте, что там НЕТ кириллических URL
- Все города должны быть в формате `/city/krasnogorsk` (латиница)

### 5. Мониторинг
Проверяйте каждые 3-5 дней:
- **Индексация → Диагностика** - не должно быть ошибок canonical
- **Индексация → Страницы в поиске** - количество проиндексированных страниц

## Ожидаемые сроки
- **1-3 дня**: Яндекс обнаружит noindex на кириллических URL
- **5-7 дней**: Кириллические URL исчезнут из индекса
- **7-14 дней**: Латинские URL полностью проиндексируются с правильным canonical

## Как проверить, что всё работает

### Тест 1: Проверка редиректа
1. Откройте в браузере: `https://mosoblconnect.ru/city/москва`
2. Должен произойти мгновенный переход на: `https://mosoblconnect.ru/city/moskva`

### Тест 2: Проверка meta robots
1. Откройте DevTools (F12) → Elements
2. Найдите в `<head>`: `<meta name="robots" content="noindex, nofollow">`
3. Это должно быть ТОЛЬКО для кириллических URL (до редиректа)

### Тест 3: Проверка canonical
1. Откройте: `https://mosoblconnect.ru/city/moskva` (латиница)
2. В DevTools → Elements найдите: `<link rel="canonical" href="https://mosoblconnect.ru/city/moskva">`
3. URL в canonical должен совпадать с URL страницы

## Дополнительные рекомендации

### Google Search Console
Аналогично повторите процесс для Google:
1. Откройте: https://search.google.com/search-console
2. **Индексирование → Страницы**
3. Запросите переиндексацию латинских URL
4. Следите за статусом canonical

### Robots.txt
Убедитесь, что robots.txt НЕ блокирует городские страницы:
- Откройте: `https://mosoblconnect.ru/robots.txt`
- Не должно быть: `Disallow: /city/`

### Временный запрет кириллических URL в robots.txt (Опционально)
Если переиндексация идёт медленно, можно временно заблокировать кириллицу:

```
# Временная блокировка кириллических URL городов
User-agent: Yandex
Disallow: /city/а
Disallow: /city/б
Disallow: /city/в
... (все буквы кириллицы)
```

⚠️ **Внимание**: Это радикальная мера, используйте только если переиндексация не происходит 2+ недели.

## FAQ

**Q: Потеряем ли мы позиции в поиске?**  
A: Нет. 301 редирект и canonical передают весь SEO-вес со старых URL на новые.

**Q: Сколько времени займёт полная переиндексация?**  
A: В среднем 7-14 дней для Яндекса, 5-10 дней для Google.

**Q: Нужно ли удалять страницы вручную?**  
A: Нет, достаточно noindex meta и правильного canonical. Яндекс сам исключит их из индекса.

**Q: Что если пользователь перейдёт по старой ссылке из Яндекса?**  
A: Произойдёт мгновенный редирект на правильный URL. Пользователь не заметит проблемы.
